# Typing Game

A multilingual typing survival game. Paste one prompt per line, then type the falling prompts before any column fills up.

## Features

- Supports Chinese, Japanese, English, and mixed Unicode prompts
- Uses the operating system's keyboard layout and input method
- Handles IME composition without submitting incomplete text
- Includes falling blocks, stacking, scoring, difficulty progression, and game-over results

## Development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```
